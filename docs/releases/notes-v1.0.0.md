**FM-1 emulator 1.0.0** by Transistor Labs: a free AU / VST3 / CLAP plugin that emulates the M-VAVE FM-1 pocket synth. Load a firmware package (`.fwsc`) and play it from MIDI or with the mouse on its panel.

- **macOS** (Apple silicon, macOS 12+): `.pkg` installer (AU, VST3, CLAP). It isn't notarised: right-click the .pkg and choose Open.
- **Windows** x64: setup `.exe` (VST3 + CLAP).
- **Linux** x64: `.tar.gz` with `install.sh` (VST3 + CLAP).
- The user manual and update history are attached as PDFs.

Firmware is not included. Emulation core: fm1-emu by Joakim Eriksson (MIT). This is an unofficial emulator, not affiliated with M-VAVE.
