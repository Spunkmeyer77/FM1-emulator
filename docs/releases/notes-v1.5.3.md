**FM-1 emulator 1.5.3** by Transistor Labs

- Window size: choose 75% to 125% in the Size menu, then close and reopen the plugin window; it opens at the new size in every host. The corner drag is removed, as hosts did not follow it reliably.

Downloads: macOS `.pkg` (macOS 12+, AU/VST3/CLAP; not notarised, so right-click and choose Open), Windows setup `.exe` (VST3/CLAP), Linux `.tar.gz` (VST3/CLAP). The user manual and update history are attached.

Firmware is not included. Emulation core: fm1-emu by Joakim Eriksson (MIT). This is an unofficial emulator, not affiliated with M-VAVE.
