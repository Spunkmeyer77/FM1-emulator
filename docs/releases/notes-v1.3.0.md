**FM-1 emulator 1.3.0** by Transistor Labs

- The whole unit is visible: rounded case corners, case side and shadow.
- Logo and model name with a silk-screen printed look.
- MIDI clock runs whenever the DAW has a tempo, so firmwares stay locked to it. For SLOOP, set GLO > SYSTEM > SYNC to TRS.
- Panel keys light up for incoming MIDI notes.
- Manual: new chapter on syncing to the DAW tempo.

Downloads: macOS `.pkg` (Apple silicon, macOS 12+, AU/VST3/CLAP; not notarised, so right-click and choose Open), Windows setup `.exe` (VST3/CLAP), Linux `.tar.gz` (VST3/CLAP). The user manual and update history are attached.

Firmware is not included. Emulation core: fm1-emu by Joakim Eriksson (MIT). This is an unofficial emulator, not affiliated with M-VAVE.
