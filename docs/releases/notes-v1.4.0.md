**FM-1 emulator 1.4.0** by Transistor Labs

- Resizable window: drag the bottom-right corner; the panel keeps its proportions.
- The window size is saved with the project and restored when you reopen it.
- The screen scales with the window: smoothed when shown small, sharp pixels when shown larger than its real 240 x 240.
- Manual: resizing explained in The Plugin Window.

Downloads: macOS `.pkg` (Apple silicon, macOS 12+, AU/VST3/CLAP; not notarised, so right-click and choose Open), Windows setup `.exe` (VST3/CLAP), Linux `.tar.gz` (VST3/CLAP). The user manual and update history are attached.

Firmware is not included. Emulation core: fm1-emu by Joakim Eriksson (MIT). This is an unofficial emulator, not affiliated with M-VAVE.
